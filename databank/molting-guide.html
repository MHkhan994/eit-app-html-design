Molting Protocol Guide

PRACTICAL MOLTING PROTOCOL GUIDE

Default Strategy: MODERATE CONTROLLED MOLTING

এটি Layer ও Breeder উভয়ের জন্য সবচেয়ে safe ও practical system.

1. MOLTING START করার আগে ENSURE করুন
  • ✔ Flock healthy আছে
  • ✔ Mortality normal আছে
  • ✔ Water line ঠিক আছে
  • ✔ Ventilation ঠিক আছে
  • ✔ Lighting control করা যাবে
  • ✔ Body weight acceptable
  • ✔ Uniformity ভালো
  • ✔ Vaccine schedule review করা হয়েছে
  • ✔ Deworming status review করা হয়েছে
  • ✔ External parasite check করা হয়েছে
  • ✔ Vitamin-electrolyte/mineral support ready আছে
  • ✔ Heat stress control করা যাবে

Antibiotic Note:
Routine antibiotic recommended না। Disease sign থাকলে vet advice ছাড়া antibiotic use করবেন না।

2. যে flock এ molting করবেন না
  • ❌ Sick flock
  • ❌ Disease recovery weak flock
  • ❌ High mortality flock
  • ❌ Very poor body condition
  • ❌ Severe heat stress condition
  • ❌ Breeder male খুব weak হলে
3. DAY 1–3: TRANSITION PHASE

Feed:
✔ Normal feed এর 50–60% দিন

Light:
✔ 8 hours

Water:
✔ Always normal

Expected Changes:

  • ✔ Production কমতে শুরু করবে
  • ✔ Bird একটু quiet হতে পারে
  • ✔ Feed intake naturally কমবে

Danger Signs:

  • ❌ Severe weakness
  • ❌ Water intake কমে যাওয়া
  • ❌ Heat stress
  • ❌ Mortality বেড়ে যাওয়া
AGGRESSIVE MOLTING OPTION

Only strong healthy layer flock এর জন্য।

Day 1–3:

  • ❌ Feed stop / near-zero feed
  • ✔ Water normal
  • ✔ Light 8 hours

Day 4 onward:

  • ✔ Body weight দেখে restricted feeding
  • ✔ Target weight loss 20–25%
  • ✔ Production 0–5%

Not recommended for:

  • ❌ Breeder flock
  • ❌ Weak flock
  • ❌ Disease recovery flock
  • ❌ Heat stress condition
4. DAY 4–10: RESTRICTION PHASE

Feed:

  • ✔ Normal feed এর 30–40% দিন
  • ✔ অথবা low nutrient molt diet

Light:
✔ 8 hours continue

Target:

  • ✔ Body weight loss 20–25%
  • ✔ Production 0–5%

Daily Monitor:

  • ✔ Body weight
  • ✔ Production
  • ✔ Mortality
  • ✔ Water intake
  • ✔ Droppings
  • ✔ Activity
5. DAY 11–14: TARGET CHECK PHASE

If target achieved:

  • ✔ Weight loss 20–25%
  • ✔ Production 0–5%
  • ✔ Mortality normal

Then:
➡ Recovery feeding শুরু করুন

If target not achieved:
➡ Restriction continue করুন, কিন্তু danger sign দেখলে stop করুন

Danger:

  • ❌ Weight loss >25%
  • ❌ Mortality high
  • ❌ Severe weakness
  • ➡ Immediate recovery feeding + health check
6. DAY 15–28: RECOVERY FEEDING PHASE

Feed:
✔ ধীরে ধীরে normal feed এ ফিরুন

Light:
✔ ধীরে ধীরে বাড়ান

Monitor:

  • ✔ Body weight recovery
  • ✔ Feather condition
  • ✔ Production return
  • ✔ Mortality

Breeder Extra:

  • ✔ Male condition
  • ✔ Fertility
  • ✔ Hatchability
  • ✔ Saleable chick
7. SECOND CYCLE MONITORING

Layer:

  • ✔ Egg production
  • ✔ Egg size
  • ✔ Shell quality
  • ✔ Feed cost vs egg income

Breeder:

  • ✔ Hatching egg production
  • ✔ Fertility
  • ✔ Hatchability
  • ✔ Chick quality
  • ✔ Chick price
8. APP DECISION RULE

App daily data দেখে advice দিবে:

  • 🟢 Continue Program
  • 🟡 Warning / Close Monitoring
  • 🟢 Target Achieved
  • 🔴 Danger / Start Recovery Immediately
